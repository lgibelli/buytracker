Recipe worker Recommended

For stores the built-in reader can't parse. Your worker figures out how to read a site once, caches that recipe, and every later check runs from it, free and with no per-check AI cost.

Direct Claude API Experimental pay-per-check alternative

Instead of the worker, paste an Anthropic API key and BuyTracker calls Claude directly whenever a page has no structured price. Simplest to switch on, but you pay per check rather than once per site. Without either option, unreadable pages just fall back to a plain "this page changed" nudge.

Stored locally in this browser only; sent only to Anthropic. Get a key →

Cost: billed by Anthropic directly, only for checks that use the fallback, structured-price sites stay free. Each call sends ~4k tokens of page text for a tiny reply, so on Haiku it runs well under a cent (~$0.003). A site that never exposes a structured price, checked every 6h, is ~4 calls/day (roughly 1–2¢/day, under $1/month). The recipe worker removes even that.
